# Archive

This directory contains retired docs, early drafts, and migration history. Archive files are kept for traceability and should not be treated as current product contracts.

## Rules

- Do not update archive files just to match the latest implementation.
- Add a short status note only when a file is likely to be mistaken for current documentation.
- Prefer linking to current docs instead of editing old drafts.
- Full bilingual translation is not required for archive files.

# 归档

本目录保存退役文档、早期草稿和迁移历史。归档文件用于追溯，不应被当作当前产品契约。

## 规则

- 不为了匹配最新实现而持续更新归档文件。
- 只有当某个文件容易被误认为当前文档时，才补一段简短状态说明。
- 优先链接当前文档，而不是修改旧草稿。
- archive 文件不要求完整双语翻译。
