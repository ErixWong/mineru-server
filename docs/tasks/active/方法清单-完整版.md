## 1. MCP Tools（/mcp）- 6 个

**协议**: JSON-RPC (MCP Protocol)
**适用**: Claude Desktop, Cline, 其他 MCP Client
**输入**: base64 文件内容

| Tool | 功能 | 参数 | 说明 |
|------|------|------|------|
| **parse_pdf** | 同步解析 PDF | `file_base64`, `file_name`, `backend`, `lang`, `formula_enable`, `table_enable`, `server_url`, `start_page_id`, `end_page_id` | 接收 base64 PDF，立即解析返回结果 |
| **submit_task** | 异步提交任务 | `file_base64`, `file_name`, `backend`, `lang`, `formula_enable`, `table_enable`, `server_url`, `start_page_id`, `end_page_id` | 接收 base64 PDF，提交任务返回 task_id |
| **get_task** | 查询任务状态 | `task_id`, `return_md` | 查询任务状态，返回 Markdown（可选） |
| **get_images** | 获取解析图片 | `task_id` | 获取任务的图片（Base64 格式） |
| **list_backends** | 列出解析后端 | 无 | 列出所有支持的解析后端 |
| **health_check** | 健康检查 | 无 | 检查 MinerU API 健康状态 |

---

### 1.1 parse_pdf 参数详解

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `file_base64` | string | ✅ 是 | - | Base64 编码的 PDF 文件内容 |
| `file_name` | string | 否 | null | 文件名（用于显示和扩展名识别） |
| `backend` | string | 否 | hybrid-http-client | 解析后端：pipeline, vlm-auto-engine, vlm-http-client, hybrid-auto-engine, hybrid-http-client |
| `lang` | string | 否 | ch | OCR 语言：ch, en, korean, japan 等 |
| `formula_enable` | bool | 否 | true | 启用公式识别 |
| `table_enable` | bool | 否 | true | 启用表格识别 |
| `server_url` | string | 否 | null | VLM Server URL（http-client 后端使用） |
| `start_page_id` | int | 否 | 0 | 起始页（0-indexed） |
| `end_page_id` | int | 否 | 99999 | 结束页（0-indexed） |

**返回示例**：
```json
{
  "task_id": "uuid-...",
  "status": "completed",
  "backend": "hybrid-http-client",
  "results": {
    "example": {
      "md_content": "# Document\n\nContent...",
      "middle_json": "...",
      "content_list": "..."
    }
  }
}
```

## 2. REST API（/api）- 6 个核心 + 8 个文档

**协议**: HTTP REST
**适用**: 远程 HTTP 调用，浏览器，其他 HTTP Client
**输入**: multipart/form-data 文件上传

### 2.1 核心 Endpoints（6 个）

| Endpoint | 方法 | 功能 | 输入方式 | 说明 |
|----------|------|------|---------|------|
| **/parse** | POST | 同步解析 | multipart/form-data | 上传 PDF，立即解析返回结果 |
| **/tasks** | POST | 异步提交 | multipart/form-data | 上传 PDF，提交任务返回 task_id |
| **/tasks/{id}** | GET | 查询状态 | Query params | 查询任务状态和 Markdown |
| **/tasks/{id}/images** | GET | 获取图片 | Path param | 获取任务的图片（Base64） |
| **/backends** | GET | 列出后端 | 无 | 列出所有支持的解析后端 |
| **/health** | GET | 健康检查 | 无 | 检查 MinerU API 健康状态 |

---

### 2.2 文档 Endpoints（8 个）

| Endpoint | 方法 | 功能 | 说明 |
|----------|------|------|------|
| **/docs** | GET | Swagger UI | API 文档（交互式） |
| **/redoc** | GET | ReDoc UI | API 文档（美观版） |
| **/openapi.json** | GET | OpenAPI Schema | API Schema（JSON） |
| **/docs/oauth2-redirect** | GET | OAuth2 Redirect | OAuth2 认证重定向 |
| 其他 HEAD 方法 | HEAD | HTTP HEAD | HTTP HEAD 请求（文档用） |

---

### 2.3 POST /parse 参数详解

**请求方式**: multipart/form-data

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `file` | UploadFile | ✅ 是 | - | PDF 文件上传 |
| `backend` | string | 否 | hybrid-http-client | 解析后端 |
| `lang` | string | 否 | ch | OCR 语言 |
| `formula_enable` | bool | 否 | true | 启用公式识别 |
| `table_enable` | bool | 否 | true | 启用表格识别 |
| `server_url` | string | 否 | null | VLM Server URL |
| `start_page_id` | int | 否 | 0 | 起始页 |
| `end_page_id` | int | 否 | 99999 | 结束页 |

**请求示例**：
```bash
curl -X POST http://localhost:8001/api/parse \
  -F "file=@example.pdf" \
  -F "backend=hybrid-http-client" \
  -F "lang=ch" \
  -F "formula_enable=true"
```

**返回示例**：
```json
{
  "backend": "hybrid-http-client",
  "version": "1.0.0",
  "results": {
    "example": {
      "md_content": "# Document\n\nContent..."
    }
  }
}
```

## 3. MinerU 原生 API（/mineru_api）- 通过 Proxy

**来源**: MinerU FastAPI（src/mineru/cli/fast_api.py）
**访问**: 通过 /mineru_api proxy
**输入**: multipart/form-data 文件上传

| Endpoint | 方法 | 功能 | 说明 |
|----------|------|------|------|
| **/mineru_api/file_parse** | POST | 同步解析 | MinerU 原生 API（返回 JSON/ZIP） |
| **/mineru_api/tasks** | POST | 异步提交 | MinerU 原生任务提交 |
| **/mineru_api/tasks/{id}** | GET | 查询状态 | MinerU 原生状态查询 |
| **/mineru_api/tasks/{id}/result** | GET | 获取结果 | MinerU 原生结果（JSON/ZIP） |
| **/mineru_api/health** | GET | 健康检查 | MinerU 原生健康检查 |
| **/mineru_api/docs** | GET | Swagger UI | MinerU API 文档 |

## 4. 功能对比总结

### 4.1 MCP vs REST API vs MinerU Native

| 功能 | MCP Tools | REST API | MinerU Native |
|------|-----------|----------|---------------|
| **输入方式** | base64 | multipart | multipart |
| **同步解析** | parse_pdf | /parse | /file_parse |
| **异步提交** | submit_task | /tasks | /tasks |
| **状态查询** | get_task | /tasks/{id} | /tasks/{id} |
| **结果获取** | get_task | /tasks/{id} | /tasks/{id}/result |
| **图片获取** | get_images | /tasks/{id}/images | 无独立接口 |
| **后端列表** | list_backends | /backends | 无 |
| **健康检查** | health_check | /health | /health |
| **认证支持** | 无 | 无 | 无 |
| **验证支持** | 有 | 有 | 无 |
| **错误处理** | 结构化 | 结构化 | HTTP 状态码 |
| **文档支持** | 无 | Swagger/ReDoc | Swagger/ReDoc |

---

### 4.2 输入方式对比

| API | 输入方式 | 优势 | 适用场景 |
|------|---------|------|---------|
| **MCP Tools** | base64 | JSON-RPC 标准 | Claude Desktop, Cline |
| **REST API** | multipart | HTTP 标准 | 远程调用，浏览器 |
| **MinerU Native** | multipart | MinerU 原生 | 直接使用 MinerU |

## 5. 使用建议

### 5.1 MCP Client（Claude Desktop, Cline）

**推荐使用**: MCP Tools
- ✅ 符合 MCP 协议标准
- ✅ base64 输入（JSON-RPC）
- ✅ 自动文件处理（临时文件清理）

**示例流程**：
1. `submit_task(file_base64)` → 提交任务
2. `get_task(task_id)` → 查询状态
3. `get_images(task_id)` → 获取图片

---

### 5.2 HTTP Client（浏览器，curl，Python requests）

**推荐使用**: REST API
- ✅ 标准 HTTP REST
- ✅ multipart/form-data 上传
- ✅ Swagger/ReDoc 文档

**示例流程**：
1. `POST /api/tasks` → 上传文件，提交任务
2. `GET /api/tasks/{id}` → 查询状态
3. `GET /api/tasks/{id}/images` → 获取图片

---

### 5.3 直接使用 MinerU

**推荐使用**: MinerU Native API（通过 /mineru_api proxy）
- ✅ MinerU 原生功能
- ✅ 支持所有 MinerU 特性
- ✅ 结果格式灵活（JSON/ZIP）

**示例流程**：
1. `POST /mineru_api/tasks` → 上传文件，提交任务
2. `GET /mineru_api/tasks/{id}` → 查询状态
3. `GET /mineru_api/tasks/{id}/result` → 获取结果（ZIP）
