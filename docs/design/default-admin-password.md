# 默认管理员密码行为决策

## 问题描述

当前 `admin123` 默认密码的行为如下：
- 仅在首次创建管理员账户时生效（即数据库中无 admin 用户时）
- 不会覆盖已有 `tasks.db` 中的管理员密码

这意味着：
- **空库部署**：admin 用户初始密码为 `admin123`（或 `MINERU_ADMIN_INITIAL_PASSWORD` 环境变量值）
- **已有数据库**：保持原有密码不变

## 产品口径选择

### 选项 A：仅首次初始化默认值（当前行为）

- 只要求"首次初始化默认值"
- 适用于：已生产环境不希望因代码更新而强制重置密码
- 实现：当前实现即为该策略

### 选项 B：未配置时统一恢复到默认值

- 要求"未配置 `MINERU_ADMIN_INITIAL_PASSWORD` 时统一恢复到 admin123"
- 适用于：需要强一致性，新部署必须使用统一默认密码
- 实现：需要在启动时检查环境变量，如未设置则强制重置 admin 密码

## 当前决策

**采用选项 A**：仅首次初始化默认值

理由：
1. 保持现有行为不变，避免对已有部署造成意外影响
2. 更安全：生产环境不应使用默认密码，应通过环境变量或 admin console 设置
3. 更简单：无需额外的密码重置逻辑

## 运维建议

1. **生产环境**：务必通过 `MINERU_ADMIN_INITIAL_PASSWORD` 设置强密码
2. **首次部署**：使用默认密码登录后，立即在 admin console 中修改为强密码
3. **已有部署**：如需重置密码，可通过 SQL 直接更新或删除 admin 用户后重启服务自动重建
