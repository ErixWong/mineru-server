- Keep decisions durable and concise.
- Link to task records for implementation rounds instead of copying audit logs here.
- Prefer bilingual content for maintained decision docs.
- If a design changes, update the decision document instead of leaving contradictory versions side by side.

## 维护规则

- 设计结论要长期有效、简洁清楚。
- 实现轮次和审计细节应链接到任务记录，不要复制到这里。
- 维护型决策文档优先双语。
- 如果设计变化，应更新同一份决策文档，避免并列保留互相矛盾的版本。
